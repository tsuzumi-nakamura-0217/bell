# ベルタイマー 設計書

- 作成日: 2026-10-07
- ステータス: レビュー待ち

## 1. 目的

プレゼン・発表会の時間管理用 Web アプリ。合計時間の途中の任意の時刻で、指定回数のベル（1鈴・2鈴・3鈴など）を鳴らす。ベル設定はテンプレートとしてサーバーに保存し、共有 URL で運営スタッフ間で何度でも使い回せる。

### 成功基準

- テンプレート（名前＋ベル設定のリスト）を作成・編集・削除できる
- 作成時に共有 URL が発行され、URL を知っていれば誰でも開いて使用・編集・削除できる（ログインなし）
- タイマーが指定時刻に指定回数のベルを鳴らす。タブが裏に回っても鳴るタイミングがずれない
- 最後のベル以降は超過時間をカウントし続ける

### 対象外（YAGNI）

- ログイン・アカウント
- 閲覧専用 URL / 編集権限の分離
- ベル音の選択、音源ファイルのアップロード
- 超過後の繰り返しベル
- 複数端末間でのタイマー状態の同期

## 2. 技術構成

- **フレームワーク**: Next.js（App Router, TypeScript）
- **ホスティング**: Cloudflare Workers（`@opennextjs/cloudflare` アダプター）
- **DB**: Cloudflare D1（Workers バインディング経由で Route Handlers から直接アクセス）
- **バリデーション**: zod（スキーマをクライアント・サーバーで共有）
- **テスト**: Vitest（単体）、`@cloudflare/vitest-pool-workers` または同等のローカル D1 環境（API）、Playwright（E2E）

単一プロジェクト・単一デプロイ（`wrangler deploy` 相当）で画面と API の両方を提供する。

## 3. 画面構成

### 3.1 トップ `/`

- 「新しいテンプレートを作る」ボタン → `/new`
- 「最近使ったテンプレート」一覧（localStorage）
  - 各行: テンプレート名、共有 URL を開くリンク、「一覧から外す」ボタン
  - 「一覧から外す」はブラウザ内の記録だけを消す。サーバー上のテンプレートは削除しない

### 3.2 テンプレート編集 `/new`, `/t/[id]/edit`

- テンプレート名（1〜100文字）
- ベル設定リスト。各行は「時刻（分:秒）」＋「回数（1〜5）」
  - 行の追加・削除が可能
  - 保存時に時刻の昇順に並べ替える
- 最後のベルの時刻 ＝ 終了時刻。それ以降は超過扱い
- 保存成功時:
  - 新規の場合は共有 URL `/t/[id]` を表示し、コピーボタンを出す
  - localStorage の「最近使った」に追加・更新する
- 「このテンプレートを削除」ボタン（`/t/[id]/edit` のみ）
  - 確認ダイアログ: テンプレート名を表示し「本当に削除しますか？（共有している全員が使えなくなります）」
  - 削除後はトップへ遷移し、localStorage からも除去する
- 入力エラーは該当行に表示する。保存・削除に失敗した場合はメッセージを表示し、入力内容は保持する

### 3.3 タイマー `/t/[id]`

- 大きな時間表示。タップで「経過時間 / 残り時間」を切り替える
- 次のベルまでの時間を表示する
- 全ベルのタイムライン表示（鳴り終わったベルはグレーアウト）
- 操作: スタート / 一時停止、リセット、手動ベル（1回鳴らす）。スペースキーでスタートと一時停止を切り替える
- 終了時刻を過ぎたら背景を赤くし、`+1:23` 形式で超過時間を表示する
- 全画面表示ボタン
- 「編集」ボタン → `/t/[id]/edit`
- 開いた時点で localStorage の「最近使った」に追加・更新する
- テンプレートが存在しない（未作成・削除済み）場合: 「このテンプレートは見つかりません（削除された可能性があります）」と表示し、トップへのリンクと「最近使った一覧から外す」ボタンを出す

## 4. データ

### 4.1 D1 テーブル `templates`

```sql
CREATE TABLE templates (
  id         TEXT PRIMARY KEY,   -- ランダム10文字 [a-z0-9]
  name       TEXT NOT NULL,
  bells      TEXT NOT NULL,      -- JSON: [{"at":240,"count":1}, ...]（at は秒）
  created_at INTEGER NOT NULL,   -- UNIX ミリ秒
  updated_at INTEGER NOT NULL
);
```

ベル設定は常に丸ごと読み書きするため、別テーブルにせず 1 つの JSON 列にまとめる。

### 4.2 バリデーション（zod、共通スキーマ）

- `name`: 前後の空白を除いて 1〜100 文字
- `bells`: 1〜20 個
  - `at`: 整数、1〜18000 秒（5 時間）、リスト内で重複不可
  - `count`: 整数、1〜5
- 保存時に `at` の昇順に並べ替える

### 4.3 ID 生成

暗号論的乱数で `[a-z0-9]` 10 文字を生成する。INSERT が主キー衝突で失敗した場合は最大 3 回まで再生成する。

### 4.4 localStorage（最近使ったテンプレート）

- キー: `bell:recent`
- 値: `{ id, name, lastOpenedAt }[]`。`lastOpenedAt` の降順で最大 20 件
- 読み書きは try/catch で囲み、失敗時は空の一覧として扱う

## 5. API（Next.js Route Handlers）

| メソッド | パス | 成功 | 失敗 |
|---|---|---|---|
| POST | `/api/templates` | 201 `{ id }` | 400 入力不正 |
| GET | `/api/templates/[id]` | 200 `{ id, name, bells, createdAt, updatedAt }` | 404 |
| PUT | `/api/templates/[id]` | 200 更新後のテンプレート | 400 / 404 |
| DELETE | `/api/templates/[id]` | 204 | 404 |

- 認証なし。URL（ID）を知っていれば誰でも全操作が可能
- PUT は最後に保存した内容が残る（楽観ロックなし）
- 400 のレスポンスには zod のエラー内容（`{ error, issues }`）を含める
- 想定外の例外は 500 `{ error: "internal" }` を返し、詳細はサーバーログに出す

## 6. タイマー処理

### 6.1 状態管理（純粋関数）

- 状態: `idle` → `running` ⇄ `paused`。`running` 中に終了時刻を超えたら `overtime`（`overtime` 中も一時停止・リセットは可能）
- 経過時間 = `累積経過 + (now − 直近の開始時刻)`。setInterval で加算する方式は使わない
- 時刻源は注入可能にする（テストで偽の時計を使うため）
- 画面表示は `requestAnimationFrame` で更新する

### 6.2 ベル音（Web Audio API）

- 卓上ベル風の音を Web Audio API で合成する（倍音を重ねたサイン波を指数関数的に減衰させる）。音源ファイルは使わない
- スタート / 再開時に、未来のベルをすべて `AudioContext.currentTime` 基準で予約する
  - 予約時刻 = `ctx.currentTime + (ベル時刻 − 現在の経過時間)`
  - 回数 n のベルは約 0.35 秒間隔で n 回予約する
- 一時停止 / リセット時は、予約済みのノードをすべて停止・破棄する
- AudioContext は最初のユーザー操作（スタート、手動ベル）で生成・`resume()` する
- 経過時間がすでに過ぎているベル（再開時など）は予約しない

### 6.3 画面スリープ防止

- `running` / `overtime` 中は Wake Lock API で画面スリープを防ぐ。未対応環境では何もしない
- 一時停止・リセット・ページ離脱時に解放する

## 7. エラー処理まとめ

| 状況 | 挙動 |
|---|---|
| 保存・削除時の通信エラー / 5xx | エラーメッセージを表示し、入力内容は保持する |
| 400（入力不正） | 該当フィールドにエラーを表示する（クライアント側でも事前に同じスキーマで検証） |
| 404（存在しない / 削除済み） | 3.3 の「見つかりません」画面 |
| localStorage が使えない | 「最近使った」一覧を空として扱い、他の機能には影響させない |
| Web Audio が使えない | タイマー画面に「このブラウザでは音を鳴らせません」と表示する（タイマー自体は動く） |

## 8. テスト

- **単体（Vitest）**
  - タイマーの状態遷移と経過時間の計算（偽の時計）
  - ベル予約時刻の計算（開始時・再開時、複数回ベル、過ぎたベルを除外）
  - zod スキーマ（境界値、重複、並べ替え）
  - localStorage の一覧管理（追加・更新・上限 20 件・削除・壊れたデータ）
- **API（Vitest＋ローカル D1）**
  - 作成・取得・更新・削除の正常系
  - 400（不正入力）、404（存在しない ID、削除後の取得）
- **E2E（Playwright）**
  - テンプレート作成 → 共有 URL を開く → タイマー開始 → 時計を進めてベルの発火と超過表示を確認 → 編集 → 削除 → 「見つかりません」表示
